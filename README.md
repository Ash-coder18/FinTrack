
# FinTrack – AI-Powered Expense Tracker

FinTrack is a personal expense-tracking application built with Flutter. It helps users record, organize, and monitor their expenses while integrating AI-powered assistance to make financial tracking more convenient.

## Overview

Managing daily expenses can be challenging without a structured system. FinTrack aims to simplify expense management through a mobile application that combines expense tracking, cloud-based data storage, and AI integration.

## Key Features

- **Expense Management:** Record and manage personal expenses.
- **Expense Tracking:** Organize financial records for easier monitoring.
- **Cloud Integration:** Uses Supabase for backend services and data storage.
- **AI Integration:** Integrates Google's Gemini API for AI-powered assistance.
- **Mobile Application:** Developed using Flutter for a mobile-focused experience.

## Technology Stack

| Category | Technologies |
|---|---|
| Frontend | Flutter, Dart |
| Backend / Database | Supabase |
| AI Integration | Google Gemini API |
| Development Tools | Git, GitHub |

## Project Architecture

FinTrack uses Flutter to provide the application interface, Supabase for backend and database functionality, and Google's Gemini API for AI-powered features.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Supabase account and project
- Google Gemini API key

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ash-coder18/FinTrack.git
   ```

2. Navigate to the project directory:

   ```bash
   cd FinTrack
   ```

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Configure the required Supabase credentials and Gemini API key according to the project's configuration.

5. Run the application:

   ```bash
   flutter run
   ```
